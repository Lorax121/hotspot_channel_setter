## Возможности

- Показывает каналы, которые устройство сообщает для диапазонов 2.4 и 5 ГГц, с опцией включить DFS и отключённые.
- Записывает выбранный канал в конфигурацию точки доступа, поэтому выбор сохраняется после перезагрузки.
- Показывает канал, который сейчас записан в настройках точки доступа.
- Два способа доступа — Shizuku (без root) и root; выбранный запоминается.
- Русский и английский языки.

## Требования

- Установленный и запущенный Shizuku либо root.
- Android 12 или новее для режима Shizuku.

## Поддержка версий

Список каналов и применение проверены на эмуляторах: Android 10, 11, 12, 14, 15, 16 и 17. Android 13 проверен на реальном устройстве.

| Android | Shizuku — список | Shizuku — применение | Root — список | Root — применение |
| :---: | :--- | :---: | :--- | :---: |
| 10 | нет | — | `iw list` | — |
| 11 | стандартный список, если система ничего не сообщила | ✓ | `iw list` | ✓ |
| 12–17 | capability от системы | ✓ | `iw list` | ✓ |

**Если сразу после перезагрузки в режиме Shizuku списка каналов нет** — включите точку доступа один раз: некоторые устройства сообщают системе возможности точки доступа только после её первого запуска. Затем нажмите кнопку обновления рядом с текущим каналом.

Способы, которые использует приложение:

**Список каналов**

| Способ | Режим | Android |
| :--- | :---: | :---: |
| Capability точки доступа от системы | Shizuku | 12+ |
| `dumpsys wifi` — `mCurrentSoftApCapability` (второй источник) | Shizuku, root | 13+ |
| `iw list` (основной источник) | root | 10+ |
| Стандартный список каналов | Shizuku | 11 |

**Применение канала**

| Способ | Режим | Android | Действует |
| :--- | :---: | :---: | :--- |
| Скрытый `setSoftApConfiguration` | Shizuku, root | 11+ | после перезагрузки |
| `cmd wifi force-softap-channel` | root | 11+ | до перезагрузки |

На Android 10 канал применить нельзя: системного API для этого нет, а в `cmd wifi` этой версии отсутствуют и `force-softap-channel`, и `get-allowed-channel`.

## Как это работает

- **Список каналов** — в режиме Shizuku приложение читает возможности точки доступа, которые сообщает система (Android 12 и новее), а вторым источником использует системный дамп (Android 13 и новее); на Android 11 показывается стандартный список. В режиме root используются `iw list` и дамп.
- **Применение** — канал записывается в конфигурацию точки доступа, которую использует системная точка доступа:

  ```text
  getSoftApConfiguration() -> копия с новым каналом -> setSoftApConfiguration()
  ```

- **Текущий канал** — читается тем же конфигурационным API.

В режиме Shizuku этот код выполняется в Shizuku user service с правами shell, в режиме root — во вспомогательном процессе, запущенном через `app_process`.

В режиме root канал можно также применить только на текущую сессию — устаревшей командой, которую Android 12 и новее разрешает только root:

```shell
cmd wifi force-softap-channel enabled <частота>
```

## Установка

Скачайте APK со страницы [Релизов](https://github.com/Lorax121/hotspot_channel_setter/releases). Сборки 1.0.x подписаны другим ключом, поэтому перед установкой 1.1.x старую версию нужно удалить.

## Сборка

```shell
flutter pub get
flutter build apk --release
```

Релизные сборки подписываются ключом, описанным в `android/key.properties` — файл не отслеживается Git.
