## 📋 Обзор

Это приложение, созданное на Flutter, предоставляет простой способ управлять каналом точки доступа Wi-Fi вашего Android-устройства. Оно предназначено для продвинутых пользователей и разработчиков, которым необходимо установить постоянный, незагруженный канал для тестирования, стриминга или повышения стабильности соединения.

Приложение получает список всех поддерживаемых каналов напрямую из системы, позволяет выбрать один из них и применяет его с помощью root-команды.

## ✨ Возможности

- **Список каналов**: Получает все доступные каналы Wi-Fi для диапазонов 2.4 ГГц и 5 ГГц.
- **Умная фильтрация**: По умолчанию отображает только безопасные и разрешенные к использованию каналы (не-DFS и включенные). Для опытных пользователей доступна опция "Показать все каналы".
- **Сохранение выбора**: Приложение запоминает последний примененный канал для каждого диапазона (2.4 ГГц и 5 ГГц) отдельно, что позволяет легко восстановить предпочитаемые настройки.
- **Быстрый выбор**: Отображает значки (бейджи) с последними использованными каналами для быстрого выбора.
- **Работа через Root**: Использует привилегии суперпользователя для применения настроек, недоступных для обычных приложений.
- **Многоязычность**: Интерфейс доступен на английском и русском языках.

## ⚠️ Требования

- **Наличие Root-доступа ОБЯЗАТЕЛЬНО.** Основная функциональность приложения основана на выполнении привилегированных команд. На устройствах без root-прав оно работать не будет.
- **Устройство на Android**: Приложение создано для Android.

## 🛠️ Как это работает

Приложение использует две основные root-команды, выполняемые через `su`:

1.  **Получение списка каналов**: Чтобы получить список всех каналов, поддерживаемых аппаратным обеспечением вашего устройства, приложение выполняет команду:
    ```shell
    su -c "iw list"
    ```
    Вывод этой команды содержит подробную информацию о возможностях вашего Wi-Fi модуля, включая поддерживаемые частоты и каналы для каждого диапазона. Приложение анализирует (парсит) этот вывод для построения списка выбора каналов.

2.  **Применение канала**: Когда вы нажимаете кнопку "Применить", приложение выполняет команду через системный сервис `cmd`, чтобы заставить точку доступа (SoftAP) работать на выбранной частоте:
    ```shell
    su -c "cmd wifi force-softap-channel enabled <частота>"
    ```
    Где `<частота>` — это частота выбранного канала в МГц (например, `2412` для канала 1 или `5180` для канала 36).

## 🚀 Начало работы

1.  Убедитесь, что ваше Android-устройство имеет root-доступ.
2.  Скачайте последнюю версию APK со страницы [Релизов](https://github.com/Lorax121/hotspot_channel_setter/releases).
3.  Установите APK на ваше устройство.
4.  Запустите приложение и предоставьте ему root-права, когда появится запрос от вашего менеджера root-доступа (например, Magisk).
5.  Выберите диапазон, укажите канал и нажмите "Применить".
6.  Включите вашу точку доступа Wi-Fi. Теперь она будет работать на выбранном вами канале.

## 🏗️ Сборка из исходного кода

Если вы хотите собрать проект самостоятельно:

1.  Клонируйте репозиторий:
    ```shell
    git clone https://github.com/Lorax121/hotspot_channel_setter.git
    ```
2.  Перейдите в директорию проекта:
    ```shell
    cd hotspot_channel_setter
    ```
3.  Загрузите зависимости:
    ```shell
    flutter pub get
    ```
4.  Соберите APK:
    ```shell
    flutter build apk --release
    ```
    Готовый APK-файл будет находиться в `build/app/outputs/flutter-apk/`.
